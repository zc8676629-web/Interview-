# interview++

`interview++` 是一个本地优先的面试复盘与 AI 备战工作台。你把简历、真实面试场次、高频题和回答稿放在同一套本地系统里，后续补题、复盘、生成回答、备份恢复都围绕这套本地资产继续积累。项目的核心原则很直接：代码可以开源，个人数据、简历内容、面试记录和 API Key 默认留在你的电脑上。

## 这个项目解决什么问题

很多面试准备工具只解决单点问题：要么帮你改简历，要么帮你生回答，要么只是记笔记。`interview++` 解决的是另一类问题：

- 你上传过很多简历版本，但后面回答问题时不知道该以哪一份为准
- 你记了很多真实面试题，但题目分散，后面很难复用
- 你已经沉淀了高频题，却没有统一口径和持续维护的地方
- 你想用 AI 提效，但又不想把个人内容、简历和题库交给在线平台长期保存

这个项目把这些事合到一个本地工作台里，让简历、场次、题库和回答之间形成稳定关系。

## 核心功能

### 1. 简历分析与版本管理

- 上传多份简历，保留简历历史和版本池
- 为每份简历生成简历画像与预测问题
- 支持把其中一份简历设为“当前用于 AI 回答”的唯一依据
- 后续 AI 回答、场次回答建议和全局复盘都围绕这份当前简历展开
- 简历侧栏支持切换和删除，方便你按投递方向维护多个版本

### 2. 面试场次库

- 新建真实面试场次，保存标题、原始文本和关联简历
- 支持把面试记录粘贴进系统后，交给 AI 自动整理问题
- 场次里的每道题都可以单独编辑
- 每道题都可以直接生成 AI 回答建议
- 每道题都可以快捷加入高频问题库
- 场次侧栏支持切换、删除
- 问题列表使用内嵌滚动，不依赖整页滚动，适合持续整理长场次

### 3. 高频问题库

- 支持从简历预测题或真实面试场次沉淀高频问题
- 支持手动新增高频题
- 支持删除、编辑、置顶
- 支持 AI 去重检查，减少语义重复题
- 支持为每道高频题直接生成 AI 回答建议
- 支持默认标签和自定义标签
- 编辑题目时只能选择系统默认标签和已经沉淀好的自定义标签，避免标签口径越用越乱

### 4. AI 回答与复盘能力

- 基于当前已选简历生成口语化回答建议
- 面向单题生成回答，也面向全局生成 AI 备战建议
- AI 备战建议会结合简历画像、面试场次和高频题一起给出优先级
- 支持发现哪些高频题还没有回答，哪些内容还没有真正沉淀完整

### 5. 作战总览、教程与全局检索

- 欢迎区下方提供全局检索，可跨简历、场次、题目、回答和标签统一搜索
- 作战总览展示当前沉淀量和待补重点，适合先看全局状态再行动
- 独立教程模块会告诉你先放简历、再录场次、再沉淀高频题、最后看 AI 建议
- 每个模块都有面向真实使用顺序的说明，不需要你自己猜系统该怎么用

### 6. 系统设置、本地备份与回收站

- DeepSeek API Key 和模型配置集中放在系统设置里
- 简历分析页不再重复放 Key 配置，避免入口分散
- 首次启动时必须先保存本机 API Key，并勾选开源声明与免责声明，才能进入主页
- 支持导出本地备份
- 支持导入本地备份
- 导入会覆盖当前业务数据，但保留这台机器上已经保存的 API Key
- 删除后的简历、高频题等内容会先进入回收站，支持恢复或永久删除

### 7. Windows 桌面版

- 项目支持打包为 Windows 安装包
- 安装时允许用户自选安装路径
- 首次启动必须完成 DeepSeek API Key 配置并确认免责协议
- 卸载时不主动清理用户数据
- 后续升级版本时继续保留本机配置和业务数据

## 数据边界与隐私原则

这个项目从设计上就把“代码”和“个人数据”分开了。

- API Key 默认只保存在本机配置里
- 简历原文、简历画像、面试场次、高频题、回答稿默认保存在本地
- 本地备份默认不携带 API Key
- 代码仓库可以公开，但你的业务数据不应该进仓库
- 首次进入系统前，用户必须明确同意本地数据保管责任

如果你准备把这个项目发给别人用，重点不是删一句提示文案，而是保证代码、仓库和用户本地配置真正解耦。

## 适合谁用

- 正在做长期求职准备，想把多轮面试沉淀成资产的人
- 不想把简历、题库和回答长期放在第三方云端的人
- 需要管理多个简历版本、多个真实场次的人
- 想把 AI 用在复盘、补题、统一口径上的人

## 当前项目形态

项目目前包含三层：

- 本地服务：负责数据存储、AI 调用、导入导出和业务接口
- 本地网页：负责工作台界面、教程、检索和管理操作
- Windows 桌面壳：负责打包成本地 EXE 安装版，方便直接分发

## 本地启动

```bash
npm install
npm run dev
```

默认会分别启动本地服务和本地网页。

如果你要启动桌面版开发模式：

```bash
npm run start:desktop
```

## 打包 Windows 安装包

```bash
npm run dist:win
```

打包完成后，安装包会输出到：

```text
release/interview-plus-plus-setup-<version>.exe
```

## 建议使用顺序

1. 先上传当前最常用的一份简历，确认画像和预测题是否贴近真实经历
2. 把最近的真实面试场次录进系统，优先沉淀真正被问到的问题
3. 把值得长期复用的问题加入高频问题库，补上标签、回答和置顶
4. 再生成 AI 备战建议，查看当前最该补哪一类问题
5. 在大改数据前先导出一份本地备份

## 项目目标

这个项目不是做一个“看起来像 AI 产品”的页面，而是做一套长期能用的本地面试作战系统。你可以持续上传新简历、继续补真实场次、沉淀高频题、统一回答口径，然后把这些东西一轮轮复用下去。
